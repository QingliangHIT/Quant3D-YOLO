# 按键说明:
1. 'w': Send pulse command: 1 and current pulse
2. 's': Send pulse command: 0 and current pulse
3. 'd': Increase selected var
4. 'a': Decrease selected var
5. 'right': Increase the step size
6. 'left': Decrease the step size
7. 'up': Increase step rate
8. 'down': Decrease step rate
9. 'c': Switch to next var
10. 'ctrl': Enter/exit command mode
11. 'q': Exit program
12. 'k': Get and show keep value
13. 'e': Get and toggle ENA
